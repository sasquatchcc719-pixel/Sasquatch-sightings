# Sasquatch Sightings MCP operations coverage

This inventory maps the existing Sightings application to the remote MCP adapter. It is deliberately explicit about side effects: a workflow existing in Sightings does not mean an MCP client is authorized to run it.

Status meanings:

- **Implemented** — exposed through the current read-only MCP and covered by MCP discovery/schema tests.
- **Partial** — useful read coverage exists, but the full screen/workflow is not exposed.
- **Existing, not exposed** — Sightings implements the workflow; MCP does not.
- **Blocked/missing** — a safe adapter needs a shared service, scope, approval, or canonical source that does not yet exist.
- **Outside scope** — intentionally excluded from this business-operations MCP.

The 11 production tools require the existing OAuth owner grant and `business:read`. The local v1.5 review build preserves those contracts and adds scoped draft/action tools. No new internal scope is granted by the migration: a write tool remains unusable until its exact scope is separately approved in `mcp_authorized_users`, reaches the OAuth token, and passes the live database grant check.

## Tool contracts and deployment boundary

The original seven names and schemas remain backward compatible:

`list_appointments`, `get_appointment`, `list_estimates`, `get_estimate`, `search_customers`, `get_availability`, `list_calls`.

The deployed v1.1 operations visibility layer adds:

`get_capability_catalog`, `get_business_configuration`, `search_business_records`, `get_operational_summary`.

The local v1.5 review build additionally adds:

`list_conversations`, `get_conversation`, `get_invoice`, `save_conversation_draft`, `preview_customer_update`, `execute_customer_update`, `preview_customer_message`, `execute_customer_message`, `preview_appointment_create`, `execute_appointment_create`, `preview_appointment_update`, `execute_appointment_update`, `preview_estimate_save`, `execute_estimate_save`, `preview_estimate_decision`, `execute_estimate_decision`, `preview_estimate_send`, `execute_estimate_send`, `preview_estimate_conversion`, `execute_estimate_conversion`.

The MCP server identity remains `sasquatch-sightings-read`, and the endpoint remains `/mcp`. Production remains on the 11-tool v1.1 deployment until Charles separately approves the migration, internal grants, deployment, and metadata refresh. The local v1.5 review build discovers 31 tools.

## Approval boundary for the local mutation review build

Local implementation is not a live grant. The review migration creates saved-draft, preview/idempotency, and audit tables and expands the token hook to emit only scopes already present in the owner’s revocable database grant. It does not add those scopes to Charles’s row. Production application, scope grants, deployment, and customer-action smoke tests each require separate approval.

Pricing/catalog administration, business-hours/security administration, destructive record deletion, charges, refunds, payment recording, bulk campaigns, hiring/Ranger, and arbitrary HTTP/SQL/shell/code/environment/token access remain outside this rollout. Ordinary operational actions are not declared permanently forbidden: they remain either implemented locally behind scoped confirmation or accurately listed as a remaining service extraction.

## Commercial account workspace — release 1.10.2

The commercial tools listed in `HARRY-COMMERCIAL-WORKSPACE.md` extend the
existing connector with account research, conversation evidence, dated next
actions, customer/site matching and dedicated measuring previews. The workspace
reports whether Outreach delivery is disabled, in a controlled pilot, or
autonomous. Dedicated commercial measuring preview, confirmation and recovery
use a durable idempotent operation and expose no invoice, email or SMS effect.
No direct commercial send, invoice or customer-creation action is exposed.
Ordinary appointment/estimate/contact tools
must not substitute for this workflow. Owner grants are unchanged. Deployment
and connector metadata refresh must be verified separately from source tests.
